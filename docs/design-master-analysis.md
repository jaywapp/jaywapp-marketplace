# design-master 분석

요청: 디자이너가 아닌 개발자가 웹·모바일 화면을 만들 때 결과가 어색하게 나오는 문제를 줄이기 위해, UI 요소 지식을 담은 플러그인 `design-master`를 만든다. 용도는 (1) UI 요소 질문, (2) 상황에 맞는 UI를 HTML 시안으로 제안받아 고르며 완성, (3) 고른 대로 구현, (4) 기존 화면 점검이다.

근거: 사용자가 모은 UI 교육 스크린샷 약 34장이 지식의 뼈대이고, 항목 목록은 `D:\station\.work\2026-11-12-design-master\artifacts\inventory.md`에 23개 주제로 추출되어 있다. 이 목록에는 이름과 일부 수치만 있고 설명은 없다.

질문/답변 (사용자 확인, 2026-11-12):
- 다른 디자인 스킬(impeccable, design-taste-frontend)에 의존하는가: 아니오. 독립형이다.
- 시안을 어디에 두는가: 대상 레포의 `docs/ux-concepts/<slug>/` HTML 파일, 브라우저로 연다. 아티팩트는 사용자가 요청할 때만.
- 선택은 어디서 받는가: 채팅.
- lookup의 범위: 이름, 상황, 생김새, 비교 질문 모두. 요청하면 동작하는 HTML 데모. 명령 없이 평소 대화에도 걸려야 한다.
- 지식과 구현의 관계: 지식은 스택 중립, 구현은 대상 레포 스택.
- 스크린샷 원본 이미지와 문구는 복제하지 않는다.

가정:

- 스크린샷이 더 올 수 있으므로 항목을 덧붙이기 쉬운 구조로 둔다.
