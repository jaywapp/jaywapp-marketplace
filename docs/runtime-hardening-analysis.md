# 성능 및 안정성 분석

요청: 기존 동작을 유지하면서 병목·예외 처리·회귀 테스트를 보강한다.

근거: 레지스트리 디렉터리마다 stat 호출이 발생하고 null 메타데이터가 검증기를 종료시킨다. 생성 중 오류를 건너뛰면 기존 항목이 누락될 수 있다.

질문/답변: 사용자가 질문 없이 수정을 명시하여 추가 질문 없음. 정상 출력과 순서를 호환성 기준으로 한다. UI/배포/실제 데이터 변경은 제외한다.

범위: scripts/build-registry.mjs, scripts/validate-plugin.mjs. 전체 기능 테스트 완료를 주장하지 않으며 확인한 경로부터 검증한다.
