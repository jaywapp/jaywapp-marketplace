# design-master UI 요소 가이드 콘셉트 시안

`design-master` 플러그인의 "UI 요소 가이드" 페이지를 어떤 형태로 만들지 고르기 위한 시안 3종이다.
세 시안은 같은 내용(23개 주제 내비게이션, 현재 주제 안 검색, 현재 위치 표시, 알림·피드백 9종 완성본)을 담고,
나머지 22개 주제는 들어갈 요소 이름만 보여 주는 빈 상태로 둔다.

- 시연 속 앱은 가상의 공유 장보기 목록 앱 하나로 통일했다(우유, 달걀, 두부, 대파, 사과).
- 시연은 GIF가 아니라 CSS 키프레임이다. 화면 밖 시연은 멈추고(IntersectionObserver),
  `prefers-reduced-motion`이거나 "시연 멈춤"을 누르면 대표 장면 한 장으로 바뀐다.
- 각 `index.html`은 CSS와 JS를 인라인한 단일 파일이다. 외부 리소스는 Google Fonts뿐이다.

## 보는 방법

브라우저로 각 폴더의 `index.html`을 연다(`file://`로 열려도 동작한다).

- `concept-01/index.html`
- `concept-02/index.html`
- `concept-03/index.html`

주소 뒤 `#feedback-snackbar`처럼 붙이면 해당 요소로 바로 간다. `#gestures`처럼 다른 주제를 붙이면 빈 상태를 볼 수 있다.

## 콘셉트

### 01 UI 필드 가이드 (색인형)

도감처럼 요소마다 "표본"을 싣는다. 왼쪽 색인에서 주제를 고르고, 본문은 요소별 항목을 세로로 읽어 내려간다.
각 항목은 폰 표본(시연), 이름, "언제"와 "피할 때" 표시, 닮은 요소 연결로 이루어지고, "구현 메모와 차이"를 누르면 그 자리에서 펼쳐진다.
주제 맨 위의 "어떤 걸 쓸까" 표는 상황에서 요소로 찾아가는 검색표다. 차분한 회녹색 바탕에 숲녹색 강조, 이름은 Hahmlet, 본문은 Gothic A1.
라이트와 다크를 모두 지원한다. 폰에서는 색인이 왼쪽 서랍으로 들어간다.

### 02 UI 무대 (한 장씩 넘기는 도감형)

한 번에 요소 하나만 크게 보여 준다. 조명 아래 폰이 주인공이고, 이름은 포스터처럼 크게(Black Han Sans) 쓴다.
아래 "출연 순서" 줄에서 요소를 고르고, 화살표 버튼, 키보드 좌우 키, 폰 위 스와이프로 넘긴다. 선택된 칩 아래 띠가 시연 한 주기를 따라 찬다.
자세한 내용은 데스크톱에서는 탭(구현할 때 / 차이), 폰에서는 바텀시트로 연다. 주제는 상단 가운데 전환기와 "주제 23개" 목록 창으로 바꾼다.
짙은 소나무색 무대에 복숭아색 강조를 쓰는 다크 고정 테마다.

### 03 UI 표본판 (전체를 조밀하게 펼친 표본판형)

한 주제의 9종을 한 판에 동시에 펼쳐 비교한다. 1px 선으로 나뉜 각진 칸에 표본을 꽂고, 표본마다 타이밍 띠(등장, 유지, 퇴장, 지연)와 지금 위치를 보여 준다.
위쪽 서랍 줄에서 23개 주제를 가로로 넘기고, 표본 이름을 누르면 "확대경" 대화상자에서 큰 시연, 구간별 ms, 구현 메모, 비교 대상 바로가기를 본다.
회색 판에 잉크색 선, 형광 연두는 바탕 칠로만 쓴다. 본문은 Nanum Gothic, 실제 타이밍 숫자에만 JetBrains Mono. 라이트와 다크를 지원한다.

## 서로 다른 점

| 항목 | 01 필드 가이드 | 02 무대 | 03 표본판 |
|---|---|---|---|
| 탐색 | 왼쪽 주제 색인 + 세로 스크롤 | 한 요소씩 넘김(버튼·키·스와이프) | 가로 주제 서랍 + 한 판에 전부 |
| 한 화면에 보이는 시연 | 1~2개 | 1개(크게) | 4~6개(작게) |
| 자세히 보기 | 항목 안에서 펼치기 | 탭(데스크톱) / 바텀시트(폰) | 확대경 대화상자 |
| 고유 장치 | 상황→요소 검색표 | 주기 띠가 차는 출연 순서 줄 | 등장·유지·퇴장 타이밍 띠와 ms |
| 테마 | 라이트·다크 자동 | 다크 고정 | 라이트·다크 자동 |
| 타이포 | Hahmlet + Gothic A1 | Black Han Sans + Noto Sans KR | Nanum Gothic + JetBrains Mono |
| 모양 | 둥근 모서리, 가는 선, 여백 넉넉 | 알약 버튼, 조명과 그림자 | 각진 칸, 1px 격자, 조밀 |
| 모션 방향 | 화면 쪽 움직임 최소, 펼침만 | 요소 전환 시 폰·글자 순차 등장 | 화면 쪽 움직임 없음, 재생 위치선만 |
| 잘 맞는 쓰임 | 처음부터 차근차근 읽기 | 하나씩 집중해서 익히기 | 비슷한 것끼리 나란히 비교 |
| 약점 | 스크롤이 길다 | 여러 요소를 한눈에 비교하기 어렵다 | 폰에서 글자가 작고 빽빽하다 |
