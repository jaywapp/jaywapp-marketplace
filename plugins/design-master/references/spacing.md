# 스페이싱 (모바일 스페이싱 가이드)

간격이 일정하면 화면이 정돈되어 보인다. 간격이 들쭉날쭉한 것이 "어색한 화면"의 가장 흔한 원인이다.

> 우선순위: 이 문서의 수치는 사용자가 모은 가이드의 기본값이다. 대상 레포에 이미 간격 체계(토큰, 유틸리티 클래스, 디자인 시스템)가 있으면 그것이 우선이고, 이 수치는 그 체계에서 가장 가까운 값으로 옮겨 쓴다.

## A. 모바일 기본 수치

| 위치 | 값 | 이유 |
|---|---|---|
| 화면 좌우 여백 | 24px | 콘텐츠와 기기 가장자리 분리, 가독성, 여러 해상도 대응의 표준 수치 |
| 제목과 콘텐츠 사이 | 16px | 헤드라인과 본문의 위계, 가까이 둘수록 한 묶음으로 읽힌다(근접성) |
| 섹션 사이 | 32px | 독립된 묶음 사이의 시각적 쉼, 인지 부하 감소 |
| 탭이나 카드 사이(반복 요소) | 12px | 요소 하나하나의 독립성과 리듬 |
| 버튼 사이 | 12px | 터치 오입력을 막는 안전 거리 |
| 탭 바 탭 내부 위아래 패딩 | 16px | iOS 홈 인디케이터와의 간섭을 줄이고 하단 균형 유지 |

사용 순서: 좌우 24px를 먼저 고정하고, 섹션 32px와 요소 12px의 2단계로 위계를 만든 뒤, 제목과 내용 16px로 가까움을 조절한다. 같은 종류의 관계에는 항상 같은 값을 쓴다.

참고: 좁은 폰(폭 360px 이하)에서는 좌우 여백을 16~20px로 줄여도 된다. 이 경우 줄인 값을 모든 화면에서 같게 적용한다.

## B. 8px 기반 체계

- 모든 간격과 크기를 8의 배수(8, 16, 24, 32, 40, 48, 64)로 하고, 작은 보정에만 4px를 쓴다. 위 모바일 수치 중 12px는 8px 체계의 중간값(1.5배)이며 4px 단위로 허용한다.
- 토큰으로 정의한다: `--space-1: 4px; --space-2: 8px; --space-3: 12px; --space-4: 16px; --space-6: 24px; --space-8: 32px; --space-12: 48px; --space-16: 64px`. 화면 코드에 임의의 값(13px, 18px, 27px)을 직접 쓰지 않는다.
- 테두리나 면으로 묶이지 않은 묶음은 안쪽 간격을 묶음 사이 간격보다 작게 한다(근접성). 이 규칙은 경계가 없는 묶음에만 적용한다. 카드처럼 테두리나 배경 면이 있는 묶음은 경계가 묶음을 구분해 주므로 안쪽 여백이 카드 사이 간격보다 커도 된다(예: 안쪽 16px, 카드 사이 12px).
- 글자 크기와 줄 높이는 4px 격자에 맞추면 정렬이 쉽다(예: 16/24, 14/20, 20/28).
- 터치 요소 높이는 44~48px(40px 이하는 피한다). 버튼 안 좌우 패딩은 16~24px.

## C. 웹 데스크톱 대응 기준

| 항목 | 모바일 기본 | 태블릿~데스크톱 대응 |
|---|---|---|
| 좌우 여백 | 24px | 태블릿 32~40px, 데스크톱은 콘텐츠를 `max-width` 컨테이너(1080~1280px)에 두고 가운데 정렬. 넓은 화면에서 여백이 자동으로 늘어난다 |
| 섹션 사이 | 32px | 48~96px. 랜딩의 큰 섹션은 80~120px도 쓴다 |
| 제목과 콘텐츠 사이 | 16px | 16~24px |
| 카드 사이 | 12px | 16~24px(격자 간격) |
| 버튼 사이 | 12px | 12px 유지(마우스 환경에서도 같은 값으로 충분) |
| 본문 줄 길이 | 화면 폭에 맞춤 | 라틴 문자 기준 45~75자(약 `65ch`), 한글은 대략 한 줄 30~40자(`max-width` 약 `36em`)로 제한 |

- 반응형 값은 `clamp()`로 부드럽게 올린다. 예: `padding-inline: clamp(24px, 5vw, 64px)`.
- 데스크톱에서도 같은 관계에는 같은 값을 쓴다. 화면 폭이 커질수록 단계(섹션, 요소)의 차이를 더 크게 두어 위계를 유지한다.
- 밀도가 높은 업무 화면(표, 관리자)은 요소 사이 8px, 섹션 사이 24px처럼 한 단계 조밀하게 정의하고 화면 전체에서 일관되게 쓴다.

## D. 자주 하는 실수

- 좌우 여백이 화면마다 다르다. 한 번 정한 값을 공통 컨테이너로 만든다.
- 제목과 위쪽 섹션 사이 간격이 제목과 아래 내용 사이 간격보다 작거나 같아서 제목이 어느 쪽에 속하는지 모호하다. 제목은 아래 내용에 더 가까워야 한다.
- 테두리나 면이 없는 카드(경계가 없는 묶음)에서 안쪽 패딩과 카드 사이 간격이 같거나 안쪽이 더 커서 묶음이 구분되지 않는다. 경계가 있는 카드는 안쪽 16px에 사이 12px처럼 안쪽이 커도 된다. 경계가 없으면 사이 간격을 안쪽보다 크게 한다.
- 하단 고정 버튼이 홈 인디케이터에 닿는다. `env(safe-area-inset-bottom)`을 더한다.
- 버튼 두 개가 붙어 있어 오입력이 난다. 12px 이상 띄운다.
