# 디자인 스타일 (9종)

화면의 전체적인 질감과 분위기를 정하는 선택지다. 스타일은 장식이 아니라 사용성과 접근성에 영향을 준다. 스타일을 정하기 전에 대상 레포에 이미 쓰는 스타일이 있으면 그것을 따른다. 한 화면에 여러 스타일을 섞지 않는다.

각 항목의 형식: 시각적 특징, 어울리는 제품, 접근성상 위험, CSS 구현 핵심. 기본 품질 규칙(대비, 상태)은 [quality-rules.md](quality-rules.md).

| 스타일 | 접근성 위험 | 한 줄 요약 |
|---|---|---|
| 스큐어모피즘 | 낮음~중간 | 실제 사물 질감을 흉내 낸다 |
| 플랫 디자인 | 낮음 | 질감 없이 색과 모양만 쓴다 |
| 머티리얼 | 낮음 | 종이와 그림자 규칙을 가진 시스템 |
| 뉴모피즘 | 높음 | 배경과 같은 색에서 솟고 눌린 느낌 |
| 글래스모피즘 | 중간~높음 | 반투명 흐림 유리 |
| 클레이모피즘 | 중간 | 말랑한 점토 같은 입체 |
| 네오 브루탈리즘 | 낮음 | 굵은 테두리와 강한 색, 투박한 그림자 |
| 3D 아이콘 | 낮음 | 입체 아이콘 일러스트 |
| 리퀴드 글래스 | 중간~높음 | Apple 플랫폼의 유동적인 유리 재질 |

### 스큐어모피즘 (Skeuomorphism)
- 시각적 특징: 가죽, 나무, 금속, 종이 같은 실제 사물의 질감과 그림자, 하이라이트를 세밀하게 표현.
- 어울리는 제품: 악기, 계산기, 도구처럼 실제 물건을 모사하는 앱, 게임 UI, 교육용.
- 접근성 위험: 장식이 정보를 가려 대비가 낮아지기 쉽고 이미지 에셋이 많아 성능과 해상도 대응이 부담된다. 질감 위 글자 대비 확인.
- CSS 구현 핵심: 다층 `box-shadow`(바깥+inset), `linear-gradient`로 광택, 이미지 텍스처 `background-image`. 해상도별 에셋(`image-set`). 버튼 눌림은 inset 그림자로 표현.

### 플랫 디자인 (Flat design)
- 시각적 특징: 그림자와 질감을 없애고 단색 면, 선명한 색, 단순한 아이콘, 타이포그래피로 구성.
- 어울리는 제품: 대부분의 웹·모바일 서비스의 기본 선택, 업무 도구, 빠른 로딩이 필요한 제품.
- 접근성 위험: 눌러야 하는 요소가 장식과 구분되지 않아 클릭 가능성이 모호해진다. 버튼에 면색이나 윤곽선을 확실히, 포커스 링을 명시한다.
- CSS 구현 핵심: 단색 `background`, `border-radius`, 그림자 최소(`box-shadow: none`) 또는 아주 약한 한 단계. 색 토큰을 중심으로 위계를 만든다.

### 머티리얼 (Material design)
- 시각적 특징: 종이가 쌓인 듯한 높이(elevation) 개념, 정해진 그림자 단계, 큰 색 포인트, 명확한 모션 규칙, 컴포넌트와 토큰이 시스템으로 정의되어 있다.
- 어울리는 제품: 안드로이드 앱, 구글 계열 느낌의 웹, 컴포넌트 라이브러리를 그대로 쓰는 업무 도구.
- 접근성 위험: 낮음. 시스템이 대비와 터치 영역을 규정한다. 다만 커스터마이징하면서 규칙(터치 48dp, 대비)을 깨기 쉽다.
- CSS 구현 핵심: 공식 컴포넌트 라이브러리(Material Web, MUI 등)와 디자인 토큰 사용. 높이 단계별 그림자, 상태 레이어(hover, pressed에 반투명 덮개), 리플 효과. 직접 구현하면 토큰을 한 곳에 정의한다.

### 뉴모피즘 (Neumorphism)
- 시각적 특징: 배경과 같은 색상 위에 밝은 그림자와 어두운 그림자를 함께 써서 요소가 돋아나거나 눌린 듯 보이게 한다.
- 어울리는 제품: 장식적 목업, 스마트홈 컨트롤, 제한된 소수의 버튼이 있는 단순 화면.
- 접근성 위험: 높음. 요소와 배경의 대비가 매우 낮고, 활성과 비활성 상태, 포커스 구분이 어렵다. 텍스트 대비가 부족해지기 쉽다. 실제 제품에서는 중요한 요소에 쓰지 않거나 윤곽선과 색 구분을 반드시 추가한다.
- CSS 구현 핵심: `box-shadow: 8px 8px 16px 어두운색, -8px -8px 16px 밝은색`과 눌림에 `inset`. 배경색은 중간 명도의 회색이나 단색. 글자 색은 배경과 4.5:1을 직접 계산.

### 글래스모피즘 (Glassmorphism)
- 시각적 특징: 반투명 배경과 배경 흐림(블러), 얇은 밝은 테두리로 유리판처럼 보이는 요소가 다채로운 배경 위에 떠 있다.
- 어울리는 제품: 날씨, 음악, 대시보드 위 카드 오버레이, 배경 이미지나 그라디언트가 있는 소비자 앱.
- 접근성 위험: 중간~높음. 뒤 배경이 바뀌면 글자 대비가 바뀐다. 가독성 확인은 가장 밝고 가장 복잡한 배경 위에서 한다. 흐림 효과는 성능 비용이 크다.
- CSS 구현 핵심: `background: rgba(255,255,255,0.12~0.25)`, `backdrop-filter: blur(12~24px) saturate(1.2)`, `border: 1px solid rgba(255,255,255,0.2~0.3)`. `@supports not (backdrop-filter: blur(1px))`에 불투명한 대체 배경. 글자 아래에 충분히 어두운(또는 밝은) 오버레이.

### 클레이모피즘 (Claymorphism)
- 시각적 특징: 점토를 빚은 듯 둥글고 통통한 모양, 부드러운 파스텔색, 안쪽 하이라이트와 바깥의 부드러운 그림자.
- 어울리는 제품: 어린이·교육 앱, 친근한 브랜드, 일러스트 중심 랜딩.
- 접근성 위험: 중간. 파스텔 색의 글자 대비가 낮기 쉽고 큰 그림자가 정보 밀도를 낮춘다.
- CSS 구현 핵심: 큰 `border-radius`(20~32px), 이중 inset 그림자(`inset 0 -8px 12px 어두운색, inset 0 8px 12px 밝은색`) + 바깥 `box-shadow: 0 12px 24px rgba(…,0.2)`. 색은 같은 계열의 두세 톤. 글자는 짙은 색으로 대비 확보.

### 네오 브루탈리즘 (Neo brutalism)
- 시각적 특징: 굵은 검은 테두리, 번지지 않는 단단한 그림자(오프셋만), 강한 원색 면, 투박한 글꼴, 격자 정렬.
- 어울리는 제품: 개발자·크리에이터 도구, 신생 브랜드의 개성 강한 랜딩, 캐주얼 앱.
- 접근성 위험: 낮음. 대비가 높아 읽기 쉽다. 다만 색이 강해 눈이 피로하고 정보 위계가 모두 같은 강도가 되기 쉽다. 강조는 한 곳에만.
- CSS 구현 핵심: `border: 2~3px solid #000`, `box-shadow: 4px 4px 0 #000`(블러 0), 눌림 시 `transform: translate(2px, 2px)`와 그림자 축소. 모서리는 각지게(0~8px). 색 팔레트 3~4개로 제한.

### 3D 아이콘 (3D icon)
- 시각적 특징: 입체감, 광택, 부드러운 그림자를 가진 렌더링 아이콘이나 일러스트. 보통 이미지 에셋이다.
- 어울리는 제품: 기능 소개 랜딩, 온보딩 일러스트, 빈 화면, 보상 연출. 작은 UI 아이콘(탭바, 툴바)에는 어울리지 않는다.
- 접근성 위험: 낮음. 장식 이미지는 `alt=""`로 처리하고 의미는 글로 전달한다. 에셋 용량과 다크 모드 대응이 부담.
- CSS 구현 핵심: PNG, WebP, 또는 SVG와 `<picture>` 해상도 대응. 배경을 투명하게 하고 다크 모드에서 그림자 색 조정. 같은 광원(왼쪽 위), 같은 각도로 세트를 통일. 용량 제한을 위해 지연 로딩.

### 리퀴드 글래스 (Liquid glass)
- 시각적 특징: Apple 플랫폼(iOS, macOS 등)이 제시한 재질로, 뒤 내용을 굴절·반사하듯 보여 주는 반투명하고 유동적인 유리 표면이 탭바, 버튼, 시트에서 형태를 바꾸며 반응한다.
- 어울리는 제품: Apple 플랫폼의 네이티브 앱(시스템 컴포넌트가 제공). 같은 느낌을 낸 소비자 웹.
- 접근성 위험: 중간~높음. 글래스모피즘과 같은 배경 의존 대비 문제가 있고 움직임이 많다. Apple은 투명도 감소와 모션 감소 설정을 제공하므로 이를 존중해야 한다.
- CSS 구현 핵심: 웹에서는 네이티브 재질을 그대로 재현할 수 없고 `backdrop-filter: blur() saturate()` 기반의 근사(반투명 배경, 안쪽 하이라이트 테두리, 미세한 그라디언트)다. 네이티브 앱은 시스템 컴포넌트를 쓰는 편이 정확하다. `prefers-reduced-motion`이 켜지면 정적인 대체를 보인다. `prefers-reduced-transparency`는 브라우저 지원이 제한적이므로 이 미디어 쿼리가 지원되지 않아도 읽히도록 기본 배경 불투명도를 충분히 높게(글자 대비 4.5:1이 되도록) 잡고, 지원되는 환경에서만 불투명 대체를 추가한다.
