# AI 채팅 화면 (9종)

AI 대화형 화면의 요소다. 일반 메신저와 달리 답변이 생성되는 시간, 틀릴 수 있다는 점, 출처 확인, 재시도가 UI의 핵심이다. 로딩과 입력의 일반 규칙은 [empty-loading.md](empty-loading.md), [inputs.md](inputs.md).

화면 기본 구성: 위에 대화 목록(스크롤), 아래에 고정된 입력창(Auto grow, [inputs.md](inputs.md)). 사용자 말풍선과 AI 답변을 구분하되 AI 답변은 긴 글을 읽기 쉽게 폭 전체나 넓은 말풍선을 쓴다. 입력창과 목록 사이에 전송 상태가 보이게 한다.

### 생각 중 표시 (Thinking indicator)
- 무엇: 답변이 시작되기 전까지 AI가 처리 중임을 알리는 표시(점 세 개, 반짝이는 문구, 작은 애니메이션).
- 언제: 요청을 보낸 뒤 첫 글자가 도착하기 전.
- 피할 때: 정지 화면 상태에서 아무 표시도 없는 것, 너무 요란한 연출.
- 구현 주의: 전송 즉시 표시(100ms 이내). 5초 넘으면 `생각하는 중…` 같은 문구나 진행 단서를 추가하고 10초가 넘으면 오래 걸림을 알리고 중지 방법을 둔다. 답변이 오기 시작하면 그 자리에서 자연스럽게 교체. `role="status"`, `prefers-reduced-motion`이면 정적 텍스트.
- 비슷한 것: 스피너(일반 로딩), 에이전트 단계(구체적 작업 표시).

### 스트리밍 답변 (Streaming response)
- 무엇: 답변이 생성되는 대로 글이 이어서 나타나는 표시.
- 언제: 모든 AI 채팅 답변.
- 구현 주의: 일반 규칙은 [empty-loading.md](empty-loading.md)의 스트리밍 텍스트. 채팅에서는 자동 스크롤(사용자가 위로 올리면 멈추고 `맨 아래로` 버튼), 생성 중 `중지` 버튼, 마크다운과 코드 블록이 미완성 상태로 깨져 보이지 않게 처리, 생성 중에는 복사나 피드백 버튼을 숨기고 끝나면 나타낸다.
- 비슷한 것: 타이핑([motion.md](motion.md), 연출).

### 추천 질문 칩 (Suggested prompts)
- 무엇: 빈 대화 화면이나 답변 아래에 눌러서 바로 보낼 수 있는 질문 후보 칩.
- 언제: 첫 화면에서 무엇을 물을지 막막할 때, 답변 뒤 후속 질문을 유도할 때.
- 피할 때: 5개를 넘게 늘어놓는 것, 앱 기능과 무관한 일반 질문.
- 구현 주의: 2~4개, 한 줄 길이, 눌리면 입력창에 채우거나(편집 가능) 바로 전송 중 하나로 통일. 모바일에서 가로 스크롤 칩보다 세로 목록이 읽기 쉽다. 후속 질문 칩은 다음 메시지를 보내면 사라지게 한다. 칩 일반: [confusable-pairs.md](confusable-pairs.md)의 칩과 배지.
- 비슷한 것: 빠른 답장 버튼.

### 다시 생성 (Regenerate)
- 무엇: 같은 질문에 대해 AI가 새 답변을 만들게 하는 버튼. 여러 버전이 있으면 `1/2` 같은 표시로 이동한다.
- 언제: 답변이 마음에 들지 않을 때.
- 구현 주의: 마지막 답변 아래에 아이콘과 라벨. 새 답변이 생성되어도 이전 버전을 버리지 않고 `< 1/2 >`로 오가게 한다. 어떤 버전이 이후 대화의 기준인지 보이게 한다. 생성 중에는 비활성.
- 비슷한 것: 고쳐 묻기(질문을 바꿔 다시 보낸다).

### 출처 표시 (Citations)
- 무엇: 답변의 근거가 된 문서나 웹 페이지를 번호나 칩으로 연결해 보여 주는 표시.
- 언제: 사실 확인이 필요한 답변, 검색이나 문서 기반 답변.
- 피할 때: 근거 없는 출처를 장식으로 붙이는 것(신뢰를 해친다).
- 구현 주의: 본문 문장 끝에 작은 번호 `[1]`, 눌리면 출처 제목, 도메인, 해당 구절. 답변 아래에 출처 목록. 링크는 새 탭으로 열고 `rel="noopener"`. 출처가 불러와지지 않을 때 오류 처리.
- 비슷한 것: 뱃지(알림 수와는 다른 요소).

### 답변 피드백 (Feedback buttons)
- 무엇: 답변 아래 좋아요, 싫어요, 복사 같은 작은 아이콘 버튼 묶음.
- 언제: 답변 품질 수집, 답변 재사용.
- 구현 주의: 아이콘만 쓰므로 `aria-label`과 툴팁. 터치 영역 44px. 눌리면 상태(채움)가 남고 복사는 토스트로 확인([feedback.md](feedback.md)). 싫어요 뒤에는 이유를 선택으로 짧게 묻는다([ratings-share.md](ratings-share.md)의 좋아요 싫어요). 생성이 끝난 뒤에만 보이게.
- 비슷한 것: 좋아요 싫어요(일반 평가).

### 고쳐 묻기 (Edit and resend)
- 무엇: 이전에 보낸 내 질문을 수정해서 다시 보내 새로운 답변을 받는 기능.
- 언제: 오타, 조건 추가, 질문 방향 변경.
- 구현 주의: 내 말풍선에 연필 아이콘(호버나 길게 누르기), 수정하면 그 이후 대화가 분기됨을 알린다. 이전 분기를 `1/2`처럼 오갈 수 있게 한다. 취소 가능. 수정 중에는 입력 칸이 말풍선 자리에서 열린다.
- 비슷한 것: 다시 생성(질문은 그대로).

### 파일 첨부 (File attachment)
- 무엇: 이미지, 문서 등을 대화에 붙여 보내는 기능.
- 언제: 문서 요약, 이미지 설명, 데이터 분석.
- 구현 주의: 입력창 옆 `+` 또는 클립 아이콘, 드래그 앤 드롭과 붙여넣기도 지원. 첨부된 파일은 입력창 위에 미리보기 칩(이름, 크기, 제거 x)으로 보인다. 업로드 진행률([empty-loading.md](empty-loading.md)의 진행 바)과 실패 시 재시도, 허용 형식과 크기 제한을 사전에 안내. 파일에 개인정보가 있을 수 있음을 고려해 사용 범위를 알린다.
- 비슷한 것: 태그 입력(칩으로 바뀌는 입력, [inputs.md](inputs.md)).

### 에이전트 단계 (Agent steps)
- 무엇: AI가 도구를 쓰거나 여러 작업을 순서대로 수행할 때 그 단계를 보여 주는 목록이나 접이식 영역.
- 언제: 검색, 코드 실행, 파일 편집 같은 다단계 작업을 AI가 할 때.
- 피할 때: 내부 처리 로그를 그대로 노출하는 것(사용자가 이해할 수준으로 요약한다).
- 구현 주의: 단계마다 상태 아이콘(대기, 진행, 완료, 실패)과 사람이 읽을 수 있는 문장. 기본은 접힌 한 줄 요약(`3단계 완료`), 펼치면 자세히. 진행 중에는 현재 단계를 강조. 실패 시 어느 단계에서 왜 실패했는지와 재시도. 사용자 확인이 필요한 단계(결제, 삭제)는 명확한 승인 버튼으로 멈춘다. 일반 단계 표시는 [indicators-completion.md](indicators-completion.md)의 스텝 인디케이터.
- 비슷한 것: 생각 중 표시(내용 없이 처리 중임만 알린다).
